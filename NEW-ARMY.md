# Новая армия и минималистичные фигуры

Обновление шахмат 10×10 добавляет пять новых типов фигур. В новой партии у каждой стороны есть по одной: всего на доске 54 фигуры. Старые шестипольные FEN-позиции и повторы продолжают загружаться.

| Фигура | Код | Ход и взятие | Цена в лавке |
| --- | --- | --- | --- |
| Архиепископ | H | Слон плюс конь. По диагонали на любое свободное расстояние либо прыжок 2×1. | 8 |
| Канцлер | C | Ладья плюс конь. По прямой на любое свободное расстояние либо прыжок 2×1. | 10 |
| Верблюд | L | Прыжок 3×1 или 1×3 в любую сторону, через промежуточные фигуры. | 4 |
| Страж | G | На одну соседнюю клетку в любом направлении либо прыжок ровно на две клетки по вертикали или горизонтали. Страж не является королём. | 4 |
| Пушка | A | Без взятия ходит как ладья по свободной прямой. Для взятия между пушкой и целью должна стоять ровно одна фигура любого цвета. После этого препятствия пушка берёт первую встреченную чужую фигуру; на пустую клетку за препятствием не ходит. | 5 |

Все фигуры подчиняются запрету оставлять своего короля под шахом. Конь, верблюд, страж и прыжки гибридных фигур перепрыгивают препятствия; дальний ход архиепископа и канцлера препятствия не перепрыгивает. Король не уничтожается взятием — партия заканчивается матом.

Начальные клетки новых фигур:

| Фигура | Белые | Чёрные |
| --- | --- | --- |
| Верблюд | b3 | b8 |
| Пушка | c3 | c8 |
| Архиепископ | f3 | d8 |
| Канцлер | g3 | f8 |
| Страж | i3 | i8 |

Дополнительные новые фигуры доступны у торговца по тем же правилам обмена трёх фигур. Новые типы поддерживают онлайн-синхронизацию, предходы, превращение цвета через UNO, мины, историю ходов и повторы. Обычная магия пешек и четыре варианта стандартного превращения пешки сохранены.

## Оформление

Все 15 шахматных типов имеют новый плоский двухцветный дизайн без градиентов. Форма различает тип, контрастный контур — сторону. Также обновлены шашки и дамки.

Галерея доступна по адресу `/pieces.html` или по ссылке «Все фигуры» в панели новой армии. Для повторной сборки SVG и галереи:

```text
node tools/build-piece-icons.cjs
```

Изображения находятся в `public/pieces/`; копия набора в корневой `pieces/` обновлена для старых статических страниц.

## Запуск и проверка

```text
npm ci
npm start
npm test
```

Откройте http://localhost:3000. Сервер обслуживает актуальный сайт из `public/`.

103 автоматические проверки прошли: старые шахматные правила, шашки и комбо назад, движения и взятия новых фигур, шахи, цены торговца, UNO, мины, синхронизация и покупка через онлайн-сервер. В браузере выполнены ходы всех пяти новых типов, проверены галерея из 30 шахматных SVG, отсутствие ошибок JavaScript и переключение на шашки. Проверка внешнего интернет-соединения в это обновление не входила.
