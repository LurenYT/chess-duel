# CHESS DUEL — Русские шашки

Обновление исходного CHESS DUEL 9.0. Авторский шахматный движок `public/chess10.js` сохранён без изменений. Исходная папка E:\Дуэль\chess-duel-v9 не изменялась: это отдельная готовая копия проекта.

## Запуск

Нужен Node.js 20 или новее. Откройте терминал в папке проекта:

```text
npm ci
npm start
```

Откройте http://localhost:3000. В верхнем меню «Игра» выберите «Русские шашки 8×8».

Для игры вдвоём на одном устройстве достаточно этого режима. Для онлайн-партии выберите шашки, затем «Создать онлайн-комнату» и передайте другу ссылку или код. Другой игрок автоматически получает режим комнаты. Реванш сохраняет выбранные правила.

При игре с другого компьютера сервер должен быть доступен по сети: localhost указывает на собственный компьютер каждого игрока. Публикация сайта в интернете в это обновление не входила.

## Реализованные правила

- Доска 8×8, по 12 шашек, первыми ходят белые.
- Простая шашка ходит вперёд на одну свободную клетку по диагонали; берёт в обе стороны.
- Дамка ходит по всей свободной диагонали. При взятии перепрыгивает одну вражескую фигуру и может выбрать любую свободную клетку за ней до следующего препятствия.
- При наличии взятия обычные ходы запрещены для всей стороны.
- Комбо выбирается одним действием: выберите шашку и конечную клетку всей цепочки. Шашка может менять направление, включая взятия назад. Если к одной клетке ведут разные пути, интерфейс предложит выбрать маршрут.
- По запросу владельца можно остановиться на промежуточной клетке после первого взятия. После выбранного маршрута очередь сразу переходит сопернику; отдельного дополнительного хода нет.
- На последней горизонтали шашка сразу становится дамкой и в пределах выбранного комбо может продолжить взятие как дамка.
- Побитые фигуры остаются препятствиями до конца выбранного комбо и затем удаляются все сразу. Повторное взятие той же фигуры запрещено.
- Победа при отсутствии у соперника шашек или допустимых ходов.
- Ничья по соглашению в онлайне, по троекратному повторению или после 15 ходов каждой стороны только дамками без взятия. Специальные турнирные правила ничьей по составу окончаний не реализованы.

Доступны подсветка допустимых клеток, история ходов, звуки, музыка и повторы реальных моментов. Предходы оставлены в авторских шахматах; в режиме шашек они отключены.

## Изменения

- `public/draughts.js`: независимый общий движок шашек для браузера и сервера.
- `public/app.js`: выбор движка, доски 8×8/10×10, передача очереди, история, повторы и сетевые состояния.
- `public/index.html`, `public/styles.css`: меню выбора и правила шашек, отдельное отображение панелей.
- `public/pieces/{wd,bd,wv,bv}.svg`: шашки и дамки.
- `server.js`: режим комнаты, проверка шашечных ходов и результат партии, сохранение режима при реванше.
- `tests/draughts.test.js`, `tests/online.test.js`: правила шашек, два игрока, ограничения прав, запрет второго взятия после переподключения и реванш.
- В старых тестах исправлены неверная стартовая горизонталь чёрных, обращение к отсутствующему событию `game:drop` и зависимость обычного шахматного теста от случайной магии. Правила старого движка не менялись.
- `package-lock.json`: фиксирует зависимости для `npm ci`.
