## Шаг 2: Деплой на Render.com (РЕКОМЕНДУЕТСЯ)

### 2.1 Если уже есть деплой на Render

Render **автоматически** обновит твой сайт после push на GitHub!

1. Зайди на [dashboard.render.com](https://dashboard.render.com)
2. Найди свой сервис **chess-duel**
3. Проверь логи деплоя - версия 8.0 должна уже разворачиваться
4. Дождись завершения (2-5 минут)
5. Открой свой URL и увидишь обновлённую версию с ракетами! 🚀

### 2.2 Если деплоя ещё нет - создай новый

1. Зайди на [render.com](https://render.com) и войди через GitHub
2. Нажми **"New"** → **"Web Service"**
3. Подключи репозиторий **chess-duel**
4. Render автоматически определит настройки из `render.yaml`:
   - **Name**: `chess-duel`
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. Выбери **Free** план
6. Нажми **"Create Web Service"**
7. Через 2-5 минут получишь URL типа: `https://chess-duel-xxxx.onrender.com`

1. Зайди на [railway.app](https://railway.app) через GitHub
2. **"New Project"** → **"Deploy from GitHub repo"**
3. Выбери **chess-duel**
4. Railway автоматически обнаружит Node.js и применит `railway.json`
5. В **Settings** → **Networking** → **"Generate Domain"**
6. Получишь URL типа: `https://chess-duel-production.up.railway.app`

## Шаг 4: Проверка новых возможностей

После деплоя протестируй новые фичи версии 8.0:

### ✅ Базовая проверка:
1. Главная страница загружается с новым дизайном
2. Большая шахматная доска с тёмным фоном
3. Можно создать/присоединиться к комнате
4. Фигуры двигаются плавно
5. Часы работают корректно

### 🚀 Проверка ракеты:
1. Создай локальную партию (или с другом)
2. Сыграй 50+ полуходов (25+ ходов каждой стороной)
3. Открывается **лавка k6** справа от доски
4. Обменяй 3 фигуры (суммой ≥12 очков) на ракету
5. Проверь взрыв: переместись на 3 клетки вперёд
6. Наблюдай огненную анимацию взрыва! 💥

### 💎 Проверка бриллиантовых ходов:
1. Сделай сильный тактический ход (взятие важной фигуры, мат)
2. Если ход действительно лучший - появится 💎
3. Голубая подсветка и частицы
4. Специальная звуковая фанфара

### ⚡ Проверка оптимизации онлайна:
1. Открой две вкладки и подключись к одной комнате
2. Сделай ход в первой вкладке
3. Ход должен отобразиться **мгновенно** локально
4. Через ~100-300ms подтверждение придёт с сервера
5. Во второй вкладке ход появится почти сразу

## Troubleshooting (Решение проблем)

### Проблема: Деплой завис или упал

**Решение**: 
1. Проверь логи: на Render - вкладка **"Logs"**, на Railway - **"Deployments"** → клик на деплой
2. Типичные ошибки:
   - `npm install` не завершился - проверь `package.json`
   - Порт неправильный - должен быть из `process.env.PORT`
   - Не хватает памяти - бесплатный план ограничен 512MB

### Проблема: Ракета не появляется

**Причина**: Нужно выполнить условия получения.

**Решение**:
1. **Через лавку**: сыграй минимум 50 полуходов, затем обменяй 3 фигуры суммой ≥12 очков
2. **Через сундук**: редкий шанс 2% при открытии сундука (каждые 30 полуходов)
3. Проверь, что есть свободная клетка на домашней горизонтали

### Проблема: WebSocket не подключается

**Решение**:
1. Убедись, что используешь `https://` (не `http://`)
2. Проверь, что в `server.js` есть `server.listen(PORT, '0.0.0.0')`
3. Render/Railway автоматически настраивают WebSocket - дополнительная конфигурация не нужна

### Проблема: Комнаты пропадают

**Причина**: Данные в памяти процесса, при перезапуске всё стирается.

**Решение для продакшена** (требует изменений кода):
- Добавь Redis для хранения состояния комнат
- Используй PostgreSQL для истории партий
- Настрой персистентное хранилище через Render/Railway

### Проблема: Медленная первая загрузка (Render)

**Причина**: Бесплатный план засыпает после 15 минут.

**Решения**:
1. Обновись до платного плана ($7/месяц) - никогда не спит
2. Используй UptimeRobot для "пинга" каждые 10 минут
3. Используй Railway - не засыпает

### Проблема: Бриллиантовые ходы выдаются редко

**Это нормально!** В версии 8.0 критерии очень строгие:
- Ход должен быть тактически значимым
- Усиливать позицию минимум на +170 очков
- Превосходить альтернативу на 165+ очков
- Рядовые взятия пешек обычно не получают 💎
